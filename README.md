# Allyson Costa — Electrical Engineering Portfolio

Open `index.html` in a browser to view the site. No installation or build is required.

- Edit your content in `index.html` and styling in `style.css`.
- Add `noise-spectrometer.jpg`, `mlcc.jpg`, and `motor-control.jpg` to `images/`. The script automatically replaces placeholders when these photos are available. You can also add `fpga.jpg` for a future FPGA project; no FPGA project details have been supplied yet.
- Add `resume.pdf` next to `index.html`. On an HTTP server, the script shows the resume link once the PDF is available. For direct file previews, replace the “Resume coming soon” paragraph with the link supplied in the adjacent HTML comment.

To publish, upload `index.html`, `style.css`, `script.js`, and your added assets to a static website host.
